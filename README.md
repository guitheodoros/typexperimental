# Type FX

Ferramenta client-side (WebGL2, vanilla JS, arquivo único) de tipografia experimental — distorção, degradação e colapso do texto. Fonte fixa (Archivo Black), quatro modos:

- **Blur / Grão** — borrão com granulado/dither, tipo spray atmosférico.
- **Derreter** — fios de tinta escorrendo das letras, com variações geradas por ruído (botão "nova variação").
- **Degradação** — halftone, glitch de faixas e falha de tinta, tipo fotocópia ruim.
- **Bloco denso** — texto corrido sem espaços, quebrado em linhas justificadas (escala horizontal), formando um bloco sólido.

Abra `index.html` diretamente no navegador — não precisa de servidor nem build.

## Estrutura

- `index.html` — tudo em um arquivo: HTML, CSS e JS/GLSL.
